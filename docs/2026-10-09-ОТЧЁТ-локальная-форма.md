# Medvediva — локальная форма и готовность миграции

Локальные проверки формы пройдены. Полный сайт к выпуску не готов.

## Не проверено
- Полный сайт: визуальная идентичность, остальные маршруты/параметры/якоря и реальный 404.
- Backend/доставка/consent/аналитика/chat/боты/платежи/ЛК. Никаких реальных лидов/денег.
- Safari/WebKit/Firefox, tablet/landscape/реальные телефоны, нагрузка, полноценный security/a11y/SEO. Телефоны исключены поручением.
- Сетевое отсутствие Tilda на всём будущем сайте; сейчас только текущий dist по статическому поиску не содержит подключения Tilda.
- 9 ошибок приобретения HTML не классифицированы как баги сайта.
