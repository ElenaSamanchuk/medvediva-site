# План и предварительная оценка

09.10.2026. Сегодняшний этап — инвентарь и автономный компонент; обещания завершить весь сайт сегодня нет.

| Этап | Результат | Оценка активной работы после входных данных |
|---|---|---|
| Сверка свежего экспорта | URL/page ID/ассеты/даты/redirects/integrations; классификация старых страниц | 2–4 часа |
| Главная как пилот | Vue + Tailwind, локальные ассеты, меню/якоря/адаптив без runtime Tilda | 4–8 часов |
| Общие блоки и остальные страницы | Полная карта соответствия, SEO, варианты тарифов и состояний | Пока 30–60 часов, пересчитать после классификации 120+ URL |
| Формы и бизнес-интеграции | Подтверждённая доставка на тестовом приёмнике, безопасные сценарии платежей | Зависит от backend/конфигурации; в оценку выше не гарантированно входит |
| Приёмка/развёртывание | Регресс, визуальное сравнение, отчёт, staging, план отката | 8–16 часов после реализации |

Это диапазоны трудозатрат, не обещание календарного срока. Экспорт и ответы по интеграциям могут изменить объём. Старые опубликованные URL остаются в области переноса, пока владелец не согласует иное.

Минимальные действия Елены: прислать ZIP свежего полного экспорта проекта 2075161 или путь к нему. Получатели форм/redirects можно уточнить позже; локальный перенос от этого не останавливать. Если backend пока неизвестен, оставить dry-run и явно не считать доставку принятой.
