## 09.10.2026 — уточнённая приёмка и предварительная публикация

- Перенести все страницы архива, включая старые/служебные; действующий medvediva.ru — эталон. Общие меню и футер на всех страницах, включая /invent. Расхождения документировать.
- Внутренние ссылки относительные и в текущей вкладке; внешние HTTP(S) в новой с безопасным rel. Сохранить специальные схемы. Якоря плавные, с учётом меню, прямого hash и Back. Анимации учитывать reduced-motion, без JS содержимое видно.
- Продажи ведут во внешний ЛК платформы; собственный checkout не нужен. UTM/click IDs и r сохранить по логике источника, не перезаписывать параметры назначения и не добавлять attribution в документы/специальные ссылки. Срок и first/last-touch уточнить по источнику.
- Sender — собственный виджет; найти исходную интеграцию и восстановить открытие/закрытие/адаптив. Доставка сообщений проверяется отдельно. Формы без известных получателей/обработчика не должны показывать ложный успех.
- iframe требуется заменить собственным кодом; недоступные внешние API/исходники отмечать конкретно. Перенести исходные Метрику/cookie/документы, но отключить реальные события аналитики и обращения в preview.
- Проверить SEO/404, текст и адаптив <400, реальные браузерные движки; noindex preview сохранить. Убирать конечные точки абзацев осторожно, связывать короткие русские слова NBSP без изменения фактов/юридического смысла.
- Инвентаризировать повторяющиеся исходные значения и выделить CSS tokens без редизайна/массового округления геометрии. Приёмка главной, /invent и разных типов страниц на 320/390/768/1440.
- Скорость важна при сохранении качества: оригиналы сохранять, srcset/sizes по экрану/DPR, lazy только ниже первого экрана, размеры для CLS, дедупликация/кеш/вес JS/шрифтов. WebP/AVIF только после визуального сравнения, без заметной потери деталей, цвета, прозрачности, текста и анимации.
- Последняя команда разрешает публикацию текущего незавершённого preview на согласованный сервер для демонстрации. Это заменяет прежний запрет публикации в данном объёме. DNS/чужие сервисы не менять, формы/аналитику реально не включать. Отдельный private репозиторий создан координатором; родительский Git не пушить.
- Из-за SSH timeout Елена запускает скрипт сама после подключения VPN. Перед переключением проверить конфигурацию сервера, использовать изолированные релизы и откат. HTTPS по IP требует отдельной проверки сертификата; HTTP не выдавать за HTTPS.
