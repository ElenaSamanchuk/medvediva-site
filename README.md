# Medvediva: перенос публичного сайта на Vue + Tailwind

Предварительный перенос сайта с Tilda на Vue 3 и Vite: 124 статические страницы, общий header/menu/footer, адаптивные сцены, локальные картинки и шрифты. Публичный сайт Tilda не изменялся

Приоритет проверки — главная, ПИТ, интенсив, ТВГ, инвентарь и документы из меню/футера. Полная визуальная приёмка всех страниц ещё не завершена. Формы и поддержка работают в демонстрационном режиме, без отправки сообщений. Предварительная сборка закрыта от индексации

### Локальный запуск

```sh
npm ci
npm test
npm run build:site
npm run preview
```

Адрес просмотра: `http://127.0.0.1:4176`. Для разработки — `npm run dev -- --port 5176`. Нормализованные модели страниц и ресурсы уже включены в репозиторий; исходный архив Tilda остаётся локально и не нужен для сборки
